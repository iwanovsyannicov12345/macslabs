# mac:lab — тема WordPress

Лендинг магазина техники Apple: каталог из админки, конфигуратор, корзина,
заявки и заказы сохраняются в WordPress и дублируются на почту/в Telegram.

## Установка

1. Админка → **Внешний вид → Темы → Добавить → Загрузить тему** → `maclab.zip` → «Установить» → «Активировать».
2. При активации каталог наполняется 12 демо-товарами (их можно менять или удалить).
3. **Настройки → Чтение → На главной странице отображать: статическую страницу** — создайте пустую страницу
   (например, «Главная») и выберите её. Тема покажет на ней лендинг.
4. **mac:lab → Настройки** — телефон, e-mail, адрес, часы работы, имя менеджера,
   почта для заявок, при желании токен Telegram-бота и chat id.

## Что где в админке

| Раздел | Для чего |
|---|---|
| mac:lab → Товары | Карточки каталога: название, цена, категория, плашка, характеристики, фото |
| mac:lab → Заявки | Формы «Оставить заявку» с сайта |
| mac:lab → Заказы | Оформления из корзины: состав, сумма, контакты |
| mac:lab → Настройки | Контакты и уведомления |

Фото товара берётся из «Изображения записи», а если его нет — из поля
«Файл изображения в теме» (`assets/img/…`).

## Приём заявок

Формы отправляются в REST API темы:

- `POST /wp-json/maclab/v1/lead` — заявка на подбор;
- `POST /wp-json/maclab/v1/order` — заказ из корзины.

Защита: скрытое поле-ловушка, проверка скорости заполнения и ограничение
в 5 отправок с одного IP за 10 минут.

Письма уходят через `wp_mail()`. На чистом VPS почта часто не доходит —
поставьте SMTP-плагин (например, WP Mail SMTP) или заполните Telegram:
создайте бота у @BotFather, узнайте свой chat id у @userinfobot и впишите оба значения в настройки.

## Структура

```
maclab/
├── assets/          стили, скрипты, шрифты, изображения
├── inc/
│   ├── setup.php    подключение ассетов, базовые возможности темы
│   ├── settings.php страница настроек
│   ├── products.php тип записи «Товар» и стартовый каталог
│   └── leads.php    заявки, заказы, REST, уведомления
├── template-parts/landing.php   секции лендинга
├── header.php · footer.php · front-page.php · index.php
└── style.css        только заголовок темы, стили в assets/css/style.css
```
