# mac:lab — магазин техники Apple

Тёмный лендинг-витрина для магазина MacBook: каталог, конфигуратор сборки,
корзина и заявки. Сделан в двух видах — статическая версия и полноценная
тема WordPress, где каталог и заявки живут в админке.

## Что внутри

| Папка | Что это |
|---|---|
| `site/` | Статическая версия: `index.html`, стили, скрипты, шрифты, изображения |
| `wp/maclab/` | Тема WordPress: шаблоны, типы записей, REST-приём заявок |
| `wp/deploy/` | Скрипты установки WordPress на чистый Ubuntu-сервер |

## Интерфейс

- Первый экран с анимированным wireframe-рельефом на canvas (фрактальный шум,
  карта высот считается один раз, вся сетка рисуется двумя вызовами `stroke`).
- Каталог с фильтром по категориям и подгрузкой по кнопке.
- Конфигуратор: модель, память, накопитель, цвет — цена и смета пересчитываются сразу.
- Корзина с анимацией добавления и удаления, состояние хранится в `localStorage`.
- Секция преимуществ: плашки стягиваются к центру и сливаются в одну кнопку
  (размеры интерполируются к реальным размерам кнопки, лишние слои гаснут —
  поэтому в точке сборки не видно стыков).
- Плавный скролл Lenis, появление блоков через `IntersectionObserver`,
  параллакс изображений, 3D-наклон карточек.
- Анимации отключаются при `prefers-reduced-motion` и упрощаются на слабых устройствах.

Шрифты: Unbounded (заголовки), Manrope (текст), Playfair Display (акцентный
заголовок) — все с кириллицей, подключены локально, без обращения к CDN.

## Тема WordPress

Каталог и заявки редактируются в админке, конструкторы страниц не нужны.

| Раздел | Назначение |
|---|---|
| mac:lab → Товары | Название, цена, категория, плашка, характеристики, фото |
| mac:lab → Заявки | Формы с сайта: имя, телефон, запрос, способ связи |
| mac:lab → Заказы | Оформления из корзины: состав и сумма |
| mac:lab → Настройки | Телефон, почта, адрес, часы работы, Telegram |

Формы уходят в REST-маршруты темы — `POST /wp-json/maclab/v1/lead` и
`/order`. От спама: скрытое поле-ловушка, проверка скорости заполнения
и лимит отправок с одного адреса.

### Установка

1. Собрать архив: `cd wp && zip -r maclab.zip maclab`
2. В админке: «Внешний вид → Темы → Добавить → Загрузить тему» → активировать.
   При активации каталог наполняется демо-товарами.
3. «Настройки → Чтение» → на главной показывать статическую страницу.
4. Контакты и уведомления — в «mac:lab → Настройки».

### Установка на чистый сервер

```bash
bash wp/deploy/install.sh      # nginx + PHP-FPM + MariaDB + WordPress
bash wp/deploy/setup-theme.sh  # тема и базовые плагины
```

## Статическая версия

```bash
cd site && python3 -m http.server 5178
```

Формы в ней работают в демо-режиме: показывают успешную отправку, но никуда
не отправляют — серверная часть живёт в теме WordPress.
